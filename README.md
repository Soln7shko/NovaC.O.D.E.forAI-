### Command Outfit & Dresscode Etiquette
**A New Command System for AI**

### Purpose
NovaC.O.D.E. aims to protect AI actions from unauthorized external influence while keeping decision-making authority with the user.

The concept is based on a simple principle: information received by an AI should not automatically become authority to command it.

### The Concept
**Inside the chat, the AI is at home in pajamas.**
It can communicate naturally, assist the user, analyze information, and access pre-approved informational services without additional task authorization.

**For protected external actions, the dress code applies.**
Actions that affect the outside world require clearly defined user authorization. External content cannot independently grant such authority.

Two independent systems support this separation:
*   **Guide** is the user-facing system. It helps prepare and approve tasks, establishes their boundaries, and manages user decisions.
*   **Bridge** is the independent verification system. It ensures that protected actions correspond to the user's approved task and its authorized boundaries before execution.
